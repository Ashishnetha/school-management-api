# School Management API

A Node.js + Express.js + Prisma + MySQL backend application to manage schools and retrieve schools sorted by proximity.

---

# Features

- Add new schools
- Retrieve schools sorted by nearest distance
- Prisma ORM integration
- MySQL database
- REST APIs
- Distance calculation using Haversine Formula

---

# Tech Stack

- Node.js
- Express.js
- Prisma ORM
- MySQL
- Postman
